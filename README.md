# Loops Like Literally All of Them

A JavaScript practice project covering loop syntax, array iteration, and small coding challenges.

## Project structure

```text
Loops-Like-Literally-All-of-Them/
├── README.md
├── 01-for-loop/
│   ├── basics.js
│   └── exercises.js
├── 02-while-loop/
│   ├── basics.js
│   └── exercises.js
├── 03-do-while/
├── 04-for-of/
├── 05-for-in/
├── 06-array-methods/
└── mini-challenges/
```

## Run an example

Install [Node.js](https://nodejs.org/), then run an individual file from the project directory:

```sh
node 01-for-loop/basics.js
```

Each JavaScript file is a standalone example. The topic folders are arranged so more examples and exercises can be added as the project grows.
